# System Architecture Overview

The Fraud Detection System utilizes a modular layered architecture:
1. Configuration (`src/config/`)
2. Data Contract & Quality (`src/data/`)
3. Leakage-Proof Preprocessing (`src/preprocessing/`)
4. Feature Engineering (`src/features/`)
5. Modeling (`src/models/`)
6. Decision Engine (`src/decision/`)
7. REST API (`src/api/`)
8. Dashboard (`dashboard/`)
